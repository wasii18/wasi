# Wasi - Portfolio

A high-end, digital portfolio crafted for Web Design, UI/UX, Frontend Engineering, and Brand Identity.

## Features
- Custom interactive cursor
- Fluid 3D and GSAP scroll animations
- Brutalist typography and asymmetrical layouts
- Video header & responsive design

## Deployment
This project is built with static HTML, CSS, and plain JavaScript. 
It can be deployed to Vercel instantly.

1. Push this repository to GitHub.
2. Go to [Vercel](https://vercel.com).
3. Import the repository.
4. Leave all build settings as default.
5. Deploy!

No build commands or frameworks required.
